# Temperature Monitoring and Automatic Fan Control Using Arduino

## Project Overview

An Arduino-based temperature monitoring system that measures temperature using a thermistor, displays real-time readings on an LCD, and automatically controls a cooling fan based on the sensed temperature.

## Features

* Real-time temperature monitoring using a thermistor
* Analog sensor reading and temperature conversion using Arduino
* Temperature display on an LCD
* Automatic fan ON/OFF control based on a temperature threshold
* MOSFET-based fan switching circuit

## Hardware Components

* Arduino board
* Thermistor
* LCD display
* MOSFET
* Cooling fan
* Connecting wires and supporting components

## Skills Demonstrated

* Arduino Programming
* Embedded Systems
* Sensor Interfacing
* LCD Interfacing
* Electronic Circuit Design

## Working Principle

The thermistor senses the surrounding temperature. The Arduino reads the sensor's analog output, converts it into a temperature value, and displays it on the LCD. Based on a configured temperature threshold, the Arduino controls the MOSFET switching circuit to switch the cooling fan on or off.
